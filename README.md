# Static Board

Weekly raid board, roster and availability for a Lost Ark static (EU Central).

- `index.html` is the whole page. It is built from a separate source; edit that and rebuild, do not edit this file by hand.
- `roster.json` lists the lostark.bible roster pages that the stats job reads.
- `scripts/refresh.py` reads item level and combat power from lostark.bible (one request per roster, 20 s apart) and saves them to the shared database. `.github/workflows/refresh.yml` runs it when started by hand from the Actions tab.

Viewing needs no login. Clear ticks and availability notes are open to everyone. Changing parties, runs and run plans needs the passcode, entered after clicking Edit.
